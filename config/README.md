# Live settings

Installed copies of Dannify read the files in this folder:

- `live.json`: notices and important fixes for copies already installed.
- `support-live.json`: the ways to support Dannify shown on its Support page.

Each comes with a `.dsig` file, the signature of Dannify's author. A copy
uses a file only when its signature is right, so these files are changed only
by the author. Please do not send changes to them.
