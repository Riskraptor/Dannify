What it does

Built for the way you actually listen

Not a feature list for its own sake. These are the parts that get used every day.

Press play, hear sound

A track starts in about a second. Whatever you are likely to reach for next is already lined up, so skipping does not mean waiting again.

Keep it for the train

Save anything to your library and it plays with the network off, artwork and all. No second app, no folder to manage.

Lyrics that keep up

The line being sung is the one in focus. The rest fall back. Write them yourself if a song has none.

Shrink it to a corner

A compact player with the lyrics or the queue folded underneath, pinned on top of whatever you are working on.

Make it yours

Seven palettes, real typefaces, spacing that was chosen rather than guessed. Pick once and it stays picked.

It behaves like a Windows app

Snap layouts when you hover maximize, a proper tray menu, controls on the taskbar thumbnail, and the media keys on your keyboard all work.

It remembers where you were

Close it mid song and it comes back cued to the same second, with the same queue, the same shuffle, the same repeat.

Getting it

Three steps, then forget about it

No runtime to install first. Nothing to configure afterwards.

  1. Download the installer

    One file, about 48 MB. Windows 10 or 11, 64 bit.

  2. Run it

    It installs for you alone, so there is no administrator prompt. Windows may warn about an unknown publisher the first time.

  3. Open Dannify

    Search for something and press play. Later versions arrive by themselves.

Updates

Small, quiet, and never in your way

A release is about 145 MB on disk, but between two versions almost none of it moves. Dannify works out which files it is actually missing and pulls only those, which is usually a few megabytes rather than fifty.

It says what it is doing

Checking what changed, downloading, verifying, with a real figure against each rather than a bar that sits at nothing.

It waits for you

Nothing is replaced while you are listening. The update goes in when you close the app, or right away if you would rather.

The full installer is always there

If the small path cannot be trusted for any reason, Dannify falls back to the complete installer on its own.

Questions

Before you ask

Does it cost anything?

No. Dannify is free and stays free. If you want to put something in the tip jar there is a Ko-fi link above, and another inside the app under Settings, About.

When are Linux and macOS coming?

Both are planned. The window, the tray menu and the installer are written against Windows today, so those are the parts being rewritten first.

Is the source code available?

No, not at the moment. That may change later.

Windows says it does not recognise the publisher.

The installer is not signed with a paid certificate yet. Choose More info, then Run anyway. Only ever install it from this page.

Will an update wipe my library?

No. Your music, playlists, settings and sign in live outside the program folder. Every update leaves them alone, including a reinstall over the top.

Something is broken.

Use the contact link at the bottom of this page and say what you were doing when it happened. That is enough to start with.
